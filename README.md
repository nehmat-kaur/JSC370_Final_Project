# Spotify Track Popularity Analysis 

## About the Project

This project was completed as the final assignment for **JSC370: Data Science II** at the **University of Toronto**. It explores which **audio features** are most predictive of a song’s **popularity on Spotify**, combining statistical modeling and machine learning to analyze trends in listener behavior and track success.

---

## Project Motivation & Description

In the age of streaming, understanding what makes a song popular can offer valuable insights for artists, producers, and marketers. This project investigates the relationship between Spotify track popularity and measurable audio characteristics such as:

- **Danceability**
- **Energy**
- **Valence**
- **Speechiness**
- **Tempo**
- **Genre**, and more.

Data was sourced from both an open-source Kaggle dataset and the Spotify Web API. Using this data, the project applies a range of modeling approaches — from **linear regression** to **regression trees** and **random forests** — to determine which features are most influential in predicting a track’s popularity.
